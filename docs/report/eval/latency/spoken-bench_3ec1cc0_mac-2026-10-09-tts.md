# Spoken-turn latency, headless pipeline — mac-2026-10-09-tts (3ec1cc0, 2026-10-08)

**Headless pipeline, not perceived in-browser latency.** The production web voice pipeline with the **fallback recogniser** (`whisper-1` upload), run call by call from Node on this Mac against the live providers. It excludes the Vercel study-proxy hop, MediaRecorder finalisation, audio decode, the playback queue and the start of lip-sync. The primary live recogniser (Web Speech, or SFSpeechRecognizer on iOS) delivers its transcript almost at stop and is not on this path. Pre-specified in `docs/eval/evaluation-plan.md` §18.1.
