# Spoken-turn latency, headless pipeline — mac-2026-10-09 (e65cdc2, 2026-10-08)

**Headless pipeline, not perceived in-browser latency.** The production web voice pipeline with the **fallback recogniser** (`whisper-1` upload), run call by call from Node on this Mac against the live providers.
